# Twin Paradox Distortion

二基の「コンプレッサー+ディストーション」ステージを入れ子構造に配置し、中間経路の二点のフィルターにより相互変調させる超軽量ディストーションVST3プラグインである。JUCE 8により実装する。

## 概要

本プラグインは、極めて低いCPU負荷でありながら、演奏のニュアンスに応じて有機的かつカオスに変貌するサウンドの生成を目的とする。

```
[ Input ]
   ├─► Stage 1 (外殻)  Comp A → Distortion A ◄────────┐
   │        │                                          │
   │        ▼                                          │ Filter 2 (Feedback)
   │   Filter 1 (Forward)                              │ Stage 2出力を帯域制限し
   │        │                                          │ Stage 1の歪みへ変調帰還
   │        └──────────────┐                           │
   │                       ▼                           │
   └─► Stage 2 (内殻)  Comp B → Distortion B ──────────┘
```

外殻の歪み出力がフィルターを介して内殻へ、内殻の出力が帯域制限を経て外殻の歪みへ帰還する双方向変調により、固定回路では得られない挙動を得る。詳細仕様は [SPEC.md](SPEC.md) を参照のこと。

## ビルド方法

Visual Studio 2022 および CMake 3.22 以上を要する。

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

## 留意事項

1. 本プラグインはフィードバック系DSPである。サチュレーション前段のゲインが小信号ループゲインを1を超えさせた場合、自己発振(轟音)に至る。パラメータ調整時はこの鉄則に留意されたい。
2. デプロイに際しては、既存の `.vst3` フォルダを**削除した後に**新版を複製すること(入れ子コピーによる新旧併存の既知障害があるため)。
